1 Setup

Grant-figure versions of the Carboplatin Cohort analyses, re-expressed on the eGFR difference scale.

\[ \text{eGFR difference (\%)} \;=\; \frac{\text{eGFR}_{\text{CR-CYS}} - \text{CrCl}_{\text{CG}}}{\text{CrCl}_{\text{CG}}} \times 100 \]

Both terms in the numerator are in mL/min: the CKD-EPI creatinine–cystatin C eGFR is the version adjusted for actual body surface area (ckd_epi_gfr_cre_cys_unindex, mL/min — not the 1.73 m²-indexed ckd_epi_gfr_cre_cys), matching the units of Cockcroft-Gault creatinine clearance. The result is expressed as a percentage: 0 % means the two estimators agree, +20 % means CKD-EPI Cr-Cys is 20 % higher than Cockcroft-Gault, −20 % means 20 % lower.

NoteRelationship to the eGFR ratio used on the Carboplatin page

Because egfr_difference = 100 × ((eGFR − CG) / CG) = 100 × (egfr_ratio − 1), this is a pure re-centring and rescaling of the eGFR ratio: the reference point moves from 1 to 0 %. The underlying Fine-Gray fits are therefore the same models as §9 of the Sherley project’s Carboplatin Cohort page — identical p-values. The reported subHRs differ only because this page reports them per 10 % decrease in eGFR difference, whereas §9 reports per 0.1-unit increase in the ratio; the two are reciprocals of each other.

# Save the given ggplot as an editable PowerPoint slide via rvg::dml, named by
# the calling chunk's label. Mirrors the helper in the Sherley project's
# sherley_carbo.qmd; the
# post-render script scripts/inject_pptx_links.py then injects a per-plot
# download link beneath each figure in the rendered HTML.
.save_plot_pptx <- function(p, name = NULL) {
  if (is.null(p) || !inherits(p, "ggplot")) return(invisible(NULL))
  if (is.null(name)) {
    name <- tryCatch(knitr::opts_current$get("label"), error = function(e) NULL)
  }
  if (is.null(name)) return(invisible(NULL))
  safe <- gsub("[^A-Za-z0-9]+", "_", name)
  out  <- file.path(pptx_dir, paste0(safe, ".pptx"))
  ok <- tryCatch({
    pp <- officer::read_pptx()
    pp <- officer::add_slide(pp, layout = "Title and Content", master = "Office Theme")
    pp <- officer::ph_with(
      pp,
      value = rvg::dml(ggobj = p),
      location = officer::ph_location_type(type = "body")
    )
    print(pp, target = out)
    TRUE
  }, error = function(e) FALSE)
  invisible(if (ok) paste0("plots/grant/", safe, ".pptx") else NULL)
}

# Format the exposure-effect subtitle: subHR (or HR) per `scale` units with
# 95% Wald CI and p-value, extracted from the Fine-Gray / Cox PH fit.
.hr_subtitle <- function(beta, V_beta, scale = 1,
                         hr_type = "subHR",
                         unit_label = "per 1-unit increase") {
  se   <- sqrt(V_beta)
  hr   <- exp(beta * scale)
  b1   <- exp((beta - 1.96 * se) * scale)
  b2   <- exp((beta + 1.96 * se) * scale)
  # A negative `scale` (reporting per unit DECREASE) reverses the bound order,
  # so sort rather than assuming b1 <= b2.
  lcl  <- min(b1, b2)
  ucl  <- max(b1, b2)
  pval <- 2 * (1 - pnorm(abs(beta / se)))
  p_str <- ifelse(pval < 0.001, "<0.001", sprintf("%.3f", pval))
  sprintf("%s = %.2f (95%% CI %.2f-%.2f), p = %s   (%s)",
          hr_type, hr, lcl, ucl, p_str, unit_label)
}

4 Predicted Dosing in the eGFR Difference ≤ −10 % Subgroup

The patients who would meet the −10 % randomization cutoff — those whose BSA-adjusted CKD-EPI Cr-Cys eGFR sits at least 10 % below their Cockcroft-Gault creatinine clearance. For this subgroup the table contrasts the carboplatin dose the Calvert formula would have produced from each kidney-function estimator against the dose actually given.

Predicted doses use Calvert at the patient’s own target AUC: dose = AUC × (min(eGFR, 125) + 25). Both arms cap the filtration estimate at 125 mL/min, so the comparison is symmetric — carbo_dose_cre_cys from the data pipeline already applies the cap (verified: it reproduces the capped formula exactly, and differs from the uncapped one by up to 53 mg), and the Cockcroft-Gault arm applies the same min(CG, 125).

The cap binds more often on the Cockcroft-Gault side in this subgroup — 11 of 39 patients exceed 125 mL/min by CG versus 3 of 39 by CKD-EPI Cr-Cys — which is expected, since the subgroup is selected for CG running high relative to Cr-Cys. The cap is therefore doing real work here: without it the Cr-Cys − CG dose gap would widen from −75.1 (41.1) mg to −113.2 (87.4) mg.

# mean (SD) and median (IQR) for one column, formatted to 1 dp.
.msd <- function(x) {
  x <- x[!is.na(x)]
  c(sprintf("%.1f (%.1f)", mean(x), stats::sd(x)),
    sprintf("%.1f (%.1f, %.1f)", stats::median(x),
            stats::quantile(x, .25), stats::quantile(x, .75)))
}

5 Linear subHR Curves — eGFR Difference (Carboplatin)

Mirrors §9.1–9.10 of the Sherley Carboplatin Cohort page, with the exposure re-expressed as the eGFR difference in percent (ticks every 10 %). Each curve is the adjusted Fine-Gray subdistribution hazard ratio as a smooth linear function of the eGFR difference, plotted relative to the cohort median (dotted vertical line). The dashed horizontal line marks subHR = 1. Reported subHRs are per 10 % decrease in eGFR difference, so a subHR above 1 means a larger CKD-EPI-Cr-Cys shortfall relative to Cockcroft-Gault carries higher risk. Models adjust for age, sex, ECOG score, ICI use and Cockcroft-Gault CrCl, plus baseline haemoglobin (anemia), baseline platelets (thrombocytopenia) or both (composite cytopenia outcomes).

Code 
# Defaults give the eGFR-difference curves of this section; §7.2 reuses the
# helper for the percent dose discrepancy via x_var / scale / labels / xlim.
plot_subhr_linear_diff <- function(time_var, status_var, extra_adj = NULL,
                                   outcome_label,
                                   x_var = "egfr_difference", scale = -10,
                                   unit_label = "per 10% decrease",
                                   x_lab = "eGFR difference (%)",
                                   xlim = c(-35, 45)) {
  base_adj <- c("age", "sex", "ecog_score", "ici", "cockcroft")
  keep <- c(x_var, time_var, status_var, base_adj, extra_adj)
  d <- dat %>% dplyr::select(all_of(keep)) %>% tidyr::drop_na()

  adj_df <- d[, c(base_adj, extra_adj), drop = FALSE]
  X_adj <- model.matrix(~ ., data = adj_df)[, -1, drop = FALSE]
  X <- cbind(d[[x_var]], X_adj)
  colnames(X)[1] <- x_var

  stat_num <- suppressWarnings(as.integer(as.character(d[[status_var]])))
  time_num <- as.numeric(d[[time_var]])

  fit <- tryCatch(
    cmprsk::crr(ftime = time_num, fstatus = stat_num,
                cov1 = X, failcode = 1),
    error = function(e) NULL
  )
  if (is.null(fit)) return(.plot_failed(outcome_label))

  beta   <- fit$coef[1]
  V_beta <- fit$var[1, 1]
  # x_var is in percentage points, so beta is per 1 pp. scale = -10 reports per
  # 10 % DECREASE, +10 per 10 % increase (sign handled in .hr_subtitle).
  subtitle_str <- .hr_subtitle(beta, V_beta, scale = scale,
                               hr_type = "subHR",
                               unit_label = unit_label)

  ref_x  <- median(d[[x_var]], na.rm = TRUE)
  grid_x <- seq(quantile(d[[x_var]], 0.025, na.rm = TRUE),
                quantile(d[[x_var]], 0.975, na.rm = TRUE),
                length.out = 100)

  log_hr <- beta * (grid_x - ref_x)
  se     <- sqrt((grid_x - ref_x)^2 * V_beta)

  df_plot <- tibble(
    x     = grid_x,
    subhr = exp(log_hr),
    lcl   = exp(log_hr - 1.96 * se),
    ucl   = exp(log_hr + 1.96 * se)
  )

  ggplot(df_plot, aes(x = x, y = subhr)) +
    geom_ribbon(aes(ymin = lcl, ymax = ucl), alpha = 0.2, fill = "darkorange") +
    geom_line(color = "darkorange", linewidth = 1) +
    geom_hline(yintercept = 1, linetype = "dashed", color = "grey50") +
    geom_vline(xintercept = ref_x, linetype = "dotted", color = "grey40") +
    labs(x = x_lab,
         y = "subHR (95% CI)",
         title = outcome_label,
         subtitle = subtitle_str) +
    scale_x_continuous(breaks = seq(-100, 100, 10)) +
    coord_cartesian(xlim = xlim, ylim = c(0, 4)) +
    theme_minimal(base_size = 14) +
    theme(plot.subtitle = element_text(size = 10, color = "grey25")) -> p
  .save_plot_pptx(p)
  p
}

6 Adjusted CIF — eGFR Difference < −10 % vs Others (Platinum-Related Hospitalisation)

Standardized cumulative incidence function contrasting patients with egfr_difference < -10 % (red, “exposed” — the randomization group) against all other patients (blue, “reference”). Multivariable Fine-Gray model fit with the binary exposure plus this cohort’s adjuster set (age, sex, ecog_score, ici, cockcroft); Cockcroft-Gault is retained as an adjuster so the difference variable carries no residual creatinine-clearance information. Curves are adjusted (standardized) via g-computation: for every patient predict the CIF under exposure = 1 and under exposure = 0, then average the two CIF curves over the whole cohort. Y-axis is cumulative incidence of platinum-related hospitalisation, x-axis is days from baseline; death is the competing event.

Code 
# Standardized CIF for a binary (0/1) exposure column of `dat`. Defaults give
# this section's eGFR-difference contrast; §7.3 reuses it for the excess dose.
adj_cif_binary <- function(time_var, status_var, extra_pre = NULL, label,
                           expo_var = "egfr_diff_lt_neg10",
                           lab_exp  = "eGFR diff < -10 % (exposed)",
                           lab_ref  = "eGFR diff ≥ -10 % (others)",
                           sub_exp  = "eGFR diff < -10%") {
  base_adj <- c("age", "sex", "ecog_score", "ici", "cockcroft")
  d <- dat %>%
    dplyr::select(all_of(c(time_var, status_var, expo_var,
                           base_adj, extra_pre))) %>%
    tidyr::drop_na()

  fmla <- as.formula(paste("~",
            paste(c(expo_var, base_adj, extra_pre), collapse = " + ")))
  X_full <- model.matrix(fmla, data = d)[, -1, drop = FALSE]

  stat_num <- suppressWarnings(as.integer(as.character(d[[status_var]])))
  time_num <- as.numeric(d[[time_var]])

  fit <- tryCatch(
    cmprsk::crr(ftime = time_num, fstatus = stat_num,
                cov1 = X_full, failcode = 1),
    error = function(e) NULL
  )
  if (is.null(fit)) return(.plot_failed(label))

  beta_e <- unname(fit$coef[1])
  se_e   <- sqrt(fit$var[1, 1])
  hr     <- exp(beta_e)
  lcl    <- exp(beta_e - 1.96 * se_e)
  ucl    <- exp(beta_e + 1.96 * se_e)
  pval   <- 2 * (1 - pnorm(abs(beta_e / se_e)))
  p_str  <- ifelse(pval < 0.001, "<0.001", sprintf("%.3f", pval))
  n_exp  <- sum(d[[expo_var]] == 1)
  n_ref  <- sum(d[[expo_var]] == 0)
  subtitle_str <- sprintf(
    "%s (n = %d) vs others (n = %d): subHR = %.2f (95%% CI %.2f-%.2f), p = %s",
    sub_exp, n_exp, n_ref, hr, lcl, ucl, p_str
  )

  X0 <- X_full; X0[, expo_var] <- 0
  X1 <- X_full; X1[, expo_var] <- 1

  pred0 <- predict(fit, X0)
  pred1 <- predict(fit, X1)

  times <- pred0[, 1]
  cif0  <- rowMeans(pred0[, -1, drop = FALSE])
  cif1  <- rowMeans(pred1[, -1, drop = FALSE])

  # Anchor both curves at CIF = 0 on day 0 and carry the last estimate out to
  # day 90 (end of follow-up), so the steps span the full 0–90-day axis.
  t_end <- 90
  df <- bind_rows(
    tibble(time = c(0, times, t_end), cif = c(0, cif0, tail(cif0, 1)),
           group = lab_ref),
    tibble(time = c(0, times, t_end), cif = c(0, cif1, tail(cif1, 1)),
           group = lab_exp)
  )
  df$group <- factor(df$group, levels = c(lab_exp, lab_ref))

  ymax <- max(df$cif, na.rm = TRUE)

  ggplot(df, aes(x = time, y = cif, color = group)) +
    geom_step(linewidth = 1) +
    scale_color_manual(values = setNames(c("#E31A1C", "#1F78B4"),
                                         c(lab_exp, lab_ref))) +
    scale_x_continuous(breaks = seq(0, t_end, by = 15)) +
    coord_cartesian(xlim = c(0, t_end), ylim = c(0, max(0.05, ymax * 1.05))) +
    labs(x = "Days from baseline",
         y = "Cumulative incidence",
         color = NULL,
         title = label,
         subtitle = subtitle_str) +

7 Dose Discrepancy (%) — Administered vs eGFRCR-CYS-Predicted Dose

Carboplatin dose discrepancy expressed as a percent of the eGFRCR-CYS-predicted dose:

\[ \text{Dose discrepancy (\%)} \;=\; \frac{\text{Dose}_{\text{administered}} - \text{Dose}_{\text{CR-CYS predicted}}}{\text{Dose}_{\text{CR-CYS predicted}}} \times 100 \]

The predicted dose is the Calvert dose at the patient’s own target AUC from the BSA-adjusted CKD-EPI Cr-Cys eGFR (mL/min), capped at 125 mL/min: AUC × (min(eGFR, 125) + 25) — the same carbo_dose_cre_cys used on the Sherley Carboplatin Cohort page (pipeline variable dose_diff_pct). A positive value means the administered dose was higher than predicted, a negative value lower; for example 550 mg administered versus 500 mg predicted is a +10 % discrepancy. This is the percent analogue of the Sherley paper’s excess-dose definition (≥ 25 mg above the predicted dose): here an excess dose is one ≥ 10 % above the eGFRCR-CYS-predicted dose.

Bins are 10 % wide with an axis tick at every bin edge. The red dashed line marks +10 %, the excess-dose cutoff.
